# Microsoft 365 API Pre-processing Connector

Auto-generated by EY SAM Studio. Implements the **Bridge → Source / Error**
data-quality pipeline against an HTTP/JSON API source.

## Pipeline

1. **Extract** — for each endpoint in `endpoints.json` (1 endpoint(s)),
   the connector authenticates, fetches the response (walking pagination),
   and emits one row per item with both a flattened TEXT column per
   discovered field AND the full JSONB payload (`__row`).
2. **Bridge load** — every row is inserted unchanged into the
   `bridge` schema.
3. **Pre-processing filter** — `rules.sql` is executed against the
   Bridge. This single optimized query is the result of combining
   1 approved data-quality rule(s).
4. **Schema split** — rows that violate any rule are written to the
   `error` schema (with `__rejected_at` / `__rule_id` columns); rows
   that pass every rule are promoted to the `source` schema.
5. **Post-process** — canonical rows are loaded into the `etl` schema
   via `field_mappings.sql` and `post_rules.sql`.

## Quick start

```bash
cp .env.example .env
# edit .env with your API credentials and TARGET_CONNECTION_STRING

# Local
pip install -r requirements.txt
python connector.py            # full run
python connector.py --dry-run  # bridge-load + counts only

# Container
podman-compose up --build
```

## Table naming convention

Every physical table follows `<stage>_tbl_microsoft_365_<endpoint>`
(e.g. `bridge.bridge_tbl_microsoft_365_resources`). Bare-name compat
VIEWs are emitted alongside so legacy SQL using the bare endpoint
name continues to resolve.

## Files

- `connector.py` — orchestrator
- `extractor.py` — HTTP fetch + paginate + flatten
- `bridge_loader.py` — Bridge insert
- `pre_processor.py` — runs `rules.sql`, splits Source / Error
- `schema_manager.py` — Bridge / Source / Error DDL
- `auth.py` / `http_client.py` — auth + retries
- `endpoints.json` — discovered endpoint catalogue
- `rules.sql` — optimized pre-processing filter
- `field_mappings.sql` / `post_rules.sql` — Source → ETL canonical
- `tests/test_smoke.py` — packaging smoke test
